`notepad-quick` is a free, open-source launcher for Notepad instances.

## Features
- **Launch quickly** with `npad open`
- **Terminate the process** with `npad terminate`
- Features ANSI escape codes for colors.

## Compiling

Ensure you have `gcc` installed, Once installed, run:

```bash
gcc Main.c -o npad.exe
```

Or just run:

```bash
make all
```
